Billing export

Invoices can be exported as CSV from the Invoices table. The export follows the current filters and streams rows, so large accounts don't block the page.

Columns

  • Invoice number, customer and status
  • Amount and currency, as stored
  • Issued and paid dates, in the account's timezone

Usage

const { start } = useCsvExport(rows, {
  filename: "invoices.csv",
  columns: INVOICE_COLUMNS, // header order
});
